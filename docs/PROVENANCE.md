# Provenance and license status

This private review package was prepared from small local Jev clients and routers created with AI assistance for the requester. Portable packaging and diagrams were newly authored for this package. No chat transcripts, credential stores, personal configuration files, proprietary project code or third-party logos are included.

TypeSafe documentation and official/community skills informed design concepts. Their complete text, libraries, screenshots and asset collections are not vendored. Links acknowledge references; they do not imply endorsement or ownership.

A definitive chain of rights for every contribution has not been established. Therefore **no LICENSE file or open-source grant is included in this draft**. An upstream project's MIT license does not automatically license this package. Before a public release, the owner should confirm rights to the material and choose a license. This is a release-readiness item, not a runtime requirement.

Graphics in `assets/` are newly written SVG diagrams using text and geometric shapes, without embedded raster media, third-party logos, remote fonts or scripts.
